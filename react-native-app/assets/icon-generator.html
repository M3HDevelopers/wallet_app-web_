Installation Instructions:

  1. Click "Download Icon" button above
  2. Save the file as icon.png
  3. Move it to: react-native-app/assets/icon.png
  4. Click "Download Adaptive Icon"
  5. Save as adaptive-icon.png
  6. Move to: react-native-app/assets/adaptive-icon.png
  7. Click "Download Splash Screen"
  8. Save as splash.png
  9. Move to: react-native-app/assets/splash.png
