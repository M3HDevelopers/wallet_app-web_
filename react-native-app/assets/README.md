# Assets Folder

Yahan apni images rakhein:

## Required Files:

1. **icon.png** (1024x1024 pixels)
   - App icon for home screen
   - Square image, no rounded corners
   - Forest green (#376B4B) wallet symbol on off-white (#F7F7F3) background

2. **splash.png** (1284x2778 pixels recommended)
   - Splash screen image
   - Will be shown while app loads
   - Center your logo/icon here

3. **adaptive-icon.png** (1024x1024 pixels)
   - Android adaptive icon foreground
   - Only the icon part (no background)
   - Will be combined with background color automatically

## How to Add:

1. Apni images ko rename karke yahan rakh dein
2. File names exactly match hone chahiye:
   - icon.png
   - splash.png
   - adaptive-icon.png

## Tools to Create Icons:

- Figma: https://figma.com
- Canva: https://canva.com
- Photopea: https://photopea.com (free Photoshop alternative)

## Quick Tip:

Agar aapke paas images nahi hain, toh Expo default icons use karega.
Build fail nahi hogi, bas default icon dikhega.
