How to Use This Icon:

  1. Right-click on the icon above
  2. Select "Save image as..."
  3. Name it: icon.png
  4. Save it to: react-native-app/assets/icon.png
  5. Also save as adaptive-icon.png for Android

  • Size: 1024x1024 pixels (recommended)
  • Format: PNG
  • Background: #F7F7F3 (warm off-white)
